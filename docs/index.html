A small input, a very different question

Time is not a duration.

You need to set a maintenance window. It’ll take 30 hours. Surely a time picker can handle that?

The task: run for 30 hours

The time picker

“What time is it?”

HTML's built-in time input asks for a time of day—not an elapsed duration. The clock has other plans.

06:00 is a time of day—not how long the task takes.

The duration input

“How long does it take?”

HTML has no built-in duration input. This one handles 30 hours, with a fixed HH:mm:ss.SSS display.

30:00:00.000 — a 30-hour duration, exactly as requested.

Native HTML time inputs are for times of day; HTML has no built-in control for entering a duration like 30:00:00.000. That's the gap input-duration fills. Read the source on GitHub.
