A small input, solves a very big problem

Time is not a duration.

You need to set a maintenance window. It’ll take 30 hours and 42 milliseconds. Surely a time picker can handle that?

The task: run X for 30 hours and 42 milliseconds

The problem

<input type="time">

Native HTML inputs are for times of day . Try setting this to 30 hours and 42 milliseconds. A time picker only accepts a time of day.

06:00 is a time of day—not how long the task takes.

The solution

<input-duration>

HTML has no built-in duration input. This web component handles 30 hours, plus those cheeky 42 milliseconds.

30:00:00.042 — 30 hours, 42 milliseconds. No clock math required.

Native HTML time inputs are for times of day; HTML has no built-in control for entering a duration like 30:00:00.042. That's the gap input-duration fills. Read the source on GitHub.
