Class: InputDuration

InputDuration()

new InputDuration()

Class for the Input-Duration webcomponent Boolean attributes `no-hours`, `no-minutes`, `no-seconds`, and `no-microseconds` hide their respective fields. String attributes `hours-divider`, `minutes-divider`, `seconds-divider`, and `microseconds-divider` customize the separators; the last adds a suffix after milliseconds. Divider values are rendered as text.
