Class: InputDuration

InputDuration()

new InputDuration()

Class for the Input-Duration webcomponent Boolean attributes `show-days`, `no-hours`, `no-minutes`, `no-seconds`, and `no-microseconds` control field visibility. String attributes `hours-divider`, `minutes-divider`, `seconds-divider`, and `microseconds-divider` customize the separators; `days-divider` customizes the day label. Divider values are rendered as text. The days field is slightly wider than other numeric fields and has extra spacing before its divider to emphasize the less-common unit. User edits update the public value and form state when the field changes, after its intermediate input has been normalized. The element is form-associated in supporting browsers; use `name`, `required`, and `disabled` attributes for form submission and validation.
